PRIVASI PEMBACA

Belajar tanpa formulir data pribadi.

Kebijakan ini menjelaskan versi situs yang tersedia saat ini.

Data di situs ini

Ruang Ekonomi tidak menyediakan akun pengguna, formulir pendaftaran, atau pembayaran. Pencarian, kuis, pilihan animasi, dan simulasi diproses di browser dan tidak dikirim oleh kode situs ke server pengelola. Pilihan animasi tidak disimpan setelah halaman dimuat ulang.

Analitik dan iklan

Saat ini kode situs tidak memasang layanan analitik, skrip AdSense, cookie iklan, atau tautan afiliasi. Ruang sponsor hanya penanda tempat dan tidak memuat iklan dari jaringan eksternal. Jika layanan tersebut dipasang kelak, kebijakan ini perlu diperbarui untuk menjelaskan penyedia, penggunaan data, serta pilihan persetujuan yang diperlukan.

Layanan hosting

Situs dihosting melalui GitHub Pages. GitHub dapat memproses data teknis permintaan, seperti alamat IP, sesuai kebijakan privasi GitHub. Ini terpisah dari pemrosesan kuis dan simulasi di browser.

Tautan ke situs lain

Tautan buku, rujukan resmi, dan kanal kontak membuka layanan lain. Ketika mengunjunginya, kebijakan layanan tersebut berlaku. Membaca sumber tidak memerlukan pengiriman jawaban kuis.

Pertanyaan privasi

Gunakan kanal kontak pengelola. Jangan mengirim data sensitif melalui issue publik GitHub.
